## 🧮 math_operations.py

Este archivo define un módulo personalizado llamado `math_operations`, que contiene funciones matemáticas básicas y una constante.

### 📄 Código del módulo

```python
# math_operations.py

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b != 0:
        return a / b
    else:
        return "Error: Division by zero"

PI = 3.14159
```

---

## 📥 use_math_module.py

Este script importa el módulo `math_operations` y utiliza sus funciones y constante.

### 📄 Código del script

```python
# use_math_module.py

import math_operations

result_add = math_operations.add(5, 3)
result_subtract = math_operations.subtract(10, 4)
result_multiply = math_operations.multiply(2, 6)
result_divide = math_operations.divide(15, 3)

print(f"Addition: {result_add}")
print(f"Subtraction: {result_subtract}")
print(f"Multiplication: {result_multiply}")
print(f"Division: {result_divide}")
print(f"Value of PI: {math_operations.PI}")
```

## 📁 Sobre el directorio `__pycache__`

Cuando importas un módulo, Python lo compila en bytecode y guarda el resultado en un directorio llamado `__pycache__`.  
Este proceso es automático y no requiere intervención del usuario.

Puedes ignorar este directorio con total seguridad.

# 🧩 Ejemplos Avanzados de Importación

Además del clásico `import math_operations`, Python permite otras formas:

### 🔹 Importar funciones específicas

```python
from math_operations import add, PI

print(add(10, 5))
print(PI)
```

### 🔹 Importar con alias

```python
import math_operations as mo

print(mo.multiply(3, 7))
```

### 🔹 Importar todo (no recomendado)

```python
from math_operations import *
```

# 📦 Crear un Paquete con `__init__.py`

Si quisieras convertir tu módulo en un paquete:

```
project/
│
└── math_package/
    ├── __init__.py
    └── math_operations.py
```

### Contenido de `__init__.py`

```python
from .math_operations import add, subtract, multiply, divide, PI
```

### Uso

```python
import math_package as mp

print(mp.add(2, 3))
```

Esto te permite organizar múltiples módulos dentro de una misma carpeta.

# ❓ Preguntas Frecuentes (FAQ)

### **1. ¿Por qué usar módulos?**
Para organizar mejor el código, reutilizar funciones y evitar duplicación.

### **2. ¿Qué pasa si el archivo no está en el mismo directorio?**
Debes ajustar el `PYTHONPATH` o usar rutas relativas/absolutas.

### **3. ¿Qué es `__pycache__`?**
Un directorio donde Python guarda bytecode compilado para acelerar futuras ejecuciones.

### **4. ¿Puedo tener múltiples módulos?**
Sí, tantos como necesites. Incluso puedes agruparlos en paquetes.

### **5. ¿Qué pasa si dos módulos tienen funciones con el mismo nombre?**
Debes usar alias o importaciones específicas para evitar conflictos.
