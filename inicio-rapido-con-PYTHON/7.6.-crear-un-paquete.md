## 🚀 Instalación y Configuración

### 1. Crear la Estructura del Paquete
```bash
# Crear el directorio del paquete
mkdir ~/project/geometry

# Crear los archivos necesarios
touch ~/project/geometry/__init__.py
touch ~/project/geometry/shapes.py
```

### 2. Contenido de `geometry/shapes.py`
```python
# geometry/shapes.py
import math

def circle_area(radius):
    """Calcula el área de un círculo"""
    return math.pi * radius ** 2

def rectangle_area(length, width):
    """Calcula el área de un rectángulo"""
    return length * width

def triangle_area(base, height):
    """Calcula el área de un triángulo"""
    return 0.5 * base * height
```

### 3. Contenido de `use_geometry_package.py`
```python
# use_geometry_package.py
from geometry.shapes import circle_area, rectangle_area, triangle_area

# Datos de prueba
radius = 5
length = 4
width = 6
base = 3
height = 8

# Calcular y mostrar resultados
print(f"Area of circle with radius {radius}: {circle_area(radius):.2f}")
print(f"Area of rectangle with length {length} and width {width}: {rectangle_area(length, width)}")
print(f"Area of triangle with base {base} and height {height}: {triangle_area(base, height)}")
```

## 💡 Conceptos Clave

### 🔍 ¿Para qué sirve `__init__.py`?
El archivo `__init__.py` es esencial para que Python reconozca un directorio como un paquete. Sus funciones principales son:

- **Identificador de paquete**: Indica a Python que el directorio debe ser tratado como un paquete
- **Inicialización**: Puede contener código que se ejecuta al importar el paquete
- **Control de imports**: Permite definir qué elementos se exportan cuando se usa `from package import *`
- **Organización**: Facilita la estructuración de código en módulos relacionados

### 📦 Beneficios de usar Paquetes
- **Organización**: Agrupa funcionalidades relacionadas
- **Reutilización**: Facilita compartir código entre proyectos
- **Mantenimiento**: Mejora la estructura del código
- **Escalabilidad**: Permite crecer el proyecto de manera ordenada

## 📚 Ejemplos de Uso

### Importación Completa
```python

area = geometry.shapes.circle_area(5)
```

### Importación Selectiva
```python
from geometry.shapes import circle_area
area = circle_area(5)
```

### Importación con Alias
```python
import geometry.shapes as gs
area = gs.circle_area(5)
```
