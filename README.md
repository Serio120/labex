# 🧪 LabEx — Technical Labs & Learning Resources

> A hands-on learning repository for **programming, Linux, DevOps, databases, cybersecurity, and data science**, built around practical labs, exercises, notes, and real-world learning resources.

---

## 🎯 About this repository

**LabEx** is my personal technical laboratory and learning workspace.

The goal is simple: **learn by doing**. Instead of keeping notes and theory isolated, this repository organizes practical exercises, beginner-friendly labs, technical references, and experiments that can be revisited as my skills evolve.

The repository is intentionally broad and covers several areas of software development and IT. Some sections are more complete than others and will continue to grow over time.

## 🧠 Learning Approach

The material in this repository follows a practical learning cycle:

```text
Learn → Practice → Experiment → Document → Revisit
```

The emphasis is on **hands-on practice**, with exercises and technical notes that can be used as a reference when learning or reviewing a technology.
